# BuildMate v0.4.0

Release date: 2026-09-29

## Scope

v0.4.0 turns the local-first planning prototype into a deployable application platform with a persistent authenticated API and explicit engineering-profile verification gates.

## Highlights

- persistent backend API and ownership boundary;
- immutable calculation runs;
- project-date/locality planning rules and QCVN 01 transition;
- Docker Compose web + API deployment;
- deterministic engineering-review primitives across structure, foundations, electrical and water/drainage;
- profile gate that blocks construction-ready status until clause maps, reference cases and independent professional review are present.

## Safety status

This release is suitable for planning, estimation, traceable engineering review and software integration. It does not claim signed or construction-ready structural/MEP design for issues #4 through #8.

## Validation

GitHub CI runs syntax checks, the Node test suite and Docker build validation on every push to main.
