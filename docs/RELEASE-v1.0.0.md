# BuildMate v1.0.0 — A-to-Z Planning Package

Release date: 2026-09-30

## Definition of done

The homeowner software loop is complete when a project can move from basic brief to a traceable planning package without requiring hidden developer-only steps.

v1.0 includes:

1. homeowner intake and multi-project storage;
2. planning geometry and functional program;
3. fresh market-price snapshot and budget range;
4. standards-backed calculators for the six tracked engineering domains;
5. editable preliminary structural/member schedules;
6. geometry/detailing-based material takeoff;
7. electrical and plumbing schedules;
8. technical BOQ with source/date provenance and explicit unpriced rows;
9. actual-cost and version tracking;
10. HTML/CSV/JSON export;
11. public demo regression project;
12. hosted Railway deployment with CI/Docker gates.

## Editable technical model

Users can adjust preliminary floor height, slab thickness/reinforcement, beam sizes/reinforcement, column sizes, footing dimensions/reinforcement and wall thickness. Every change recalculates quantities and BOQ.

## Boundary

v1.0 is **software-complete for planning and option studies**, not a substitute for project-specific construction design. The app intentionally continues to block or label assumptions where geotechnical evidence, member analysis, real layouts, manufacturer data, permits or professional approvals are required.
