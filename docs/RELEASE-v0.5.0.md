# BuildMate v0.5.0

Release date: 2026-09-30

v0.5.0 is the standards-first engineering release for BuildMate's initial 1-5 storey townhouse scope.

The main change is not simply more formulas. The application now treats engineering evidence as a first-class object: source-backed inputs, clause mappings, deterministic calculations, automated cases, review packets, evidence fingerprints and verified reviewer records are linked end-to-end.

This release remains an engineering-review system until qualified independent reviewers approve and verify the exact supported profiles. Unsupported cases are explicitly blocked rather than approximated.
