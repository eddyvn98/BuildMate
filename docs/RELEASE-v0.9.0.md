# BuildMate v0.9.0 — Technical Package Beta

Release date: 2026-09-30

## Goal

Turn the homeowner Beta from a planning/calculator product into a package that exposes the physical building model, quantities and BOQ users expect to see.

## Added

- Parametric structural grid for townhouse geometry.
- Slab, beam, column, footing, tie-beam and stair schedules.
- Preliminary member dimensions and reinforcement detailing.
- Concrete and formwork takeoff by component.
- Rebar calculation by bar diameter and length, including a 3% waste allowance.
- Masonry, brick, mortar, plaster, paint, tiling and waterproofing quantities.
- Electrical circuit/point schedule and cable lengths.
- Plumbing fixture schedule, PPR/uPVC pipe lengths and water-tank sizing.
- HVAC zone scope with explicit cooling-load blockers.
- Technical BOQ with rate provenance and unpriced-item backlog.
- New Technical Package web view.
- Detailed technical package in HTML report and CSV export.

## Boundary

This release produces a **preliminary technical package**. Parametric member dimensions, reinforcement and routing quantities are not construction drawings. They must be replaced or verified with project-specific load analysis, structural member calculations, geotechnical evidence and real architectural/MEP layouts before construction use.
