# BuildMate v0.7.0

Release date: 2026-09-30

## Goal

Make BuildMate behave as one A-to-Z townhouse workflow rather than a collection of calculation modules.

## Delivered

- Standards-ready semantics based on standard coverage, formula/table provenance and tests.
- Project-specific evidence gates separated from optional engineering audit/review.
- TCVN 5687:2024 residential HVAC/ventilation profile.
- HVAC comfort, outdoor-design, outdoor-air, ACH, sensible-heat airflow, component cooling-load and equipment-selection workflows.
- HVAC engineering evidence types for outdoor design conditions and equipment performance.
- HVAC conformance tests and a golden bedroom outdoor-air benchmark.
- A-to-Z project progress/status model and UI.
- Six-profile technical report/readiness coverage: loads, RC, foundations, electrical, water/drainage and HVAC.
- Engine/package version 0.7.0.

## Readiness rule

`standards-ready` means the tracked software implementation is complete and testable against its cited standard basis. A project calculation remains blocked if required project/site/manufacturer/test evidence is missing.

Optional review/audit records remain available but are not required to close a software gap.
